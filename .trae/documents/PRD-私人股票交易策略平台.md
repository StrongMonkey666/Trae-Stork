# 私人股票交易策略平台 - 产品需求文档

## 1. 产品概述

**私人股票交易策略平台**是一款专为个人投资者设计的全栈网页应用，集策略回测、实时交易、技术分析和组合管理于一体。平台利用 akshare 财经数据接口获取A股、期货、基金等多市场数据，帮助用户科学化、系统化地执行交易策略。

**核心价值**：
- 通过历史数据回测验证策略有效性，降低实盘风险
- 可视化技术分析图表，支持多指标组合
- 实时行情监控与交易执行
- 统一的组合管理界面，实时展示收益与风险

**目标用户**：具有Python编程基础的个人量化交易者、程序化交易爱好者

## 3. 核心业务流程

### 3.1 策略回测流程

```
用户创建策略 → 编写Python策略代码 → 配置回测参数（时间、资金、手续费）
    ↓
提交回测任务 → 后端拉取历史数据 → 执行策略回测引擎 → 生成回测报告
    ↓
查看绩效指标（收益率、夏普率、最大回撤） → 保存策略或调整参数
```

### 3.2 模拟交易流程

```
用户选择策略 → 绑定模拟账户 → 设置交易标的和时间
    ↓
开启模拟交易 → 实时行情触发信号 → 自动生成交易订单
    ↓
执行订单 → 更新持仓和资金 → 实时计算浮动盈亏
```

### 3.3 技术分析流程

```
用户选择股票 → 加载历史K线数据 → 添加技术指标
    ↓
调整指标参数 → 分析图表形态 → 生成交易信号建议
```

## 6. 非功能需求

### 6.1 性能要求

- 页面首次加载时间：≤ 3秒
- 图表渲染时间：≤ 500ms
- 实时行情刷新：5秒间隔
- 回测引擎：支持至少10000条历史数据

### 6.2 安全要求

- 用户密码：bcrypt加密存储
- 会话管理：JWT Token，24小时有效期
- API安全：所有接口需要认证
- 数据隔离：用户只能访问自己的数据

### 6.3 可用性要求

- 系统可用性：≥ 99.5%
- 浏览器支持：Chrome、Firefox、Safari、Edge最新两个版本
- 移动端适配：响应式设计，支持平板端访问

### 6.4 数据存储

- 用户数据：MySQL
- 策略代码：MySQL
- 历史回测结果：MySQL
- 实时行情缓存：Redis
- 文件存储：本地文件系统（策略附件、导出文件）
